Install split APKs and copy apps between Android phones

A free desktop app for Windows, Linux and macOS. Drop an .apk, .apks, .xapk or .apkm file and droid.or installs the right parts on your phone over USB, or copy an installed app straight from one phone to another. No root, no ads, no telemetry.

What it does

droid.or opens on Install. Pick the phone, then drop a file or choose where the app comes from.

Split bundles, done right

.apks, .xapk, .apkm, a folder or a set of split APKs. droid.or picks the parts that match the phone's CPU, screen density and language and installs them together.

Copy apps phone to phone

Connect two phones and copy an installed app, including its split parts, from one to the other. Useful for apps that are no longer on Google Play or not available in your region.

Know before you install

Every APK is inspected first, so you see whether it is a new install, an update, a reinstall or a downgrade before anything happens on the phone.

Device tools with an undo

Review and disable preinstalled apps, back up APKs, and see every ADB command in the log. Every change is recorded and can be restored from Recovery.

What you need

  • A USB cable that carries data, not just power.
  • USB debugging turned on in the phone's developer options. The app walks you through it on first start.
  • ADB: droid.or uses the one already on your computer or downloads Google's official platform-tools for you.
  • Windows only: your phone manufacturer's USB driver.

Is it safe?

Every claim here can be checked in the source code.

No telemetry

The only automatic network request is a daily check for a new release on GitHub, which you can switch off. Everything else happens only when you click it, including the optional, off-by-default "Ask AI" package analysis.

Verifiable downloads

Every release lists SHA-256 checksums and has a signed build provenance attestation proving it was built by the project's own release workflow.

Nothing changes without you

Every change asks for confirmation, the riskiest ones ask you to type it, and everything droid.or changed on a phone can be restored from Recovery.

Honest limits

Copying an app copies the app, not its data, accounts or logins. Apps that check Google Play licensing may refuse to run after copying.
